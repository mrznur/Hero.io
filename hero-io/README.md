# Productivity Master

A modern app-store inspired platform for discovering, installing, and managing productivity apps — built with React and Vite.

## Tech Stack

React · Vite · Tailwind CSS · DaisyUI · Recharts · React Router · React Hot Toast

## Getting Started

```bash
npm install
npm run dev
```
